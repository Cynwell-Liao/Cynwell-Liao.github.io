# Dock artwork

Original publisher assets retrieved on 10 October 2026. Artwork is stored locally so the Dock does not depend on third-party image requests.

| File           | Publisher source                                                                                                                                                                                                         |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `github.svg`   | [GitHub's website favicon](https://github.githubassets.com/favicons/favicon.svg), linked by [github.com](https://github.com). The black-and-white website icon is displayed on a white macOS-style web-app tile.         |
| `linkedin.jpg` | [LinkedIn's App Store listing](https://apps.apple.com/us/app/id288429040), original 512 × 512 artwork from the listing's `artworkUrl512`. This is the published app icon; a separate native macOS icon was not verified. |
| `terminal.svg` | [Apple's macOS 27 Terminal guide](https://support.apple.com/guide/terminal/welcome/mac), [original 400 × 400 icon](https://ipcdn-web.apple.com/assets/v2/web/39c3cf79-78d9-4c4b-b30c-64cac5415a89).                      |

LinkedIn's original artwork URL: <https://is1-ssl.mzstatic.com/image/thumb/Purple211/v4/d9/21/68/d92168df-8b53-2e21-5231-54f3962293cf/AppIcon-0-0-1x_U007emarketing-0-8-0-85-220.png/512x512bb.jpg>.

Logos and app artwork belong to their respective owners. The source artwork has not been redrawn or recolored, except for the Terminal icon which is a pixel-perfect vector recreation of the original PNG.
